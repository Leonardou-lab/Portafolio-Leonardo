0042025

Authentication Log Search System

Sorting and search performance study

C++ Merge Sort Binary Search Big O

C++ system that processes ~20,000 security log entries with timestamp-based interval and count queries.

  • Compared two strategies behind a polymorphic interface: binary insertion sort (O(n) per insert, always sorted) vs. Merge Sort on full load (O(n log n)).
  • Both use binary search for O(log n) retrieval. Single-insert and batch-insert benchmarks confirmed the theoretical complexity.
~20,000 entries, Theory verified
